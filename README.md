# R.E.D

ESP8266 project for controlling an electric toy car.

This project is part of "Software Engineering" lecture, in which we must work on a project using agile project management.
The content of the project is left to the groups working on it.

We are going to convert a RC toy car into an autonomus driving car that is controlled by an ESP8266 and an ultrasound sensor.

##Functionalities

The car should perform the following tasks:
- Break befor collision
- Scan a room
- Controlls to drive the car from a pc/controller connected to the pc
- Areas that can be used by the car and a "virtual" boarder that can't be crossed
