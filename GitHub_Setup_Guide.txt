# GitHub Setup Guide

## Step 1: Install Git
Download and install Git Bash from:
https://git-scm.com/install/

---

## Step 2: Basic Git Commands

pwd
    → Prints the current working directory.

cd "path"
    → Changes the directory to the specified path.
    Example: cd Documents/Projects

git init
    → Initializes a new Git repository in the current folder.

git status
    → Shows the current status of your repository (e.g., staged, unstaged, or untracked files).

git add <file-name>
    → Stages a specific file for commit.
    Example: git add index.html

git add .
    → Stages all changes in the current directory.

git commit -m "message"
    → Commits staged changes with a descriptive message.
    Example: git commit -m "Initial commit"

git diff
    → Shows changes between your working directory and the last commit.

git checkout -b <branch_name>
    → Creates a new branch and switches to it.
    Example: git checkout -b feature/login

git branch
    → Lists all branches in your repository.

git checkout <branch_name>
    → Switches to an existing branch.

---

## Step 3: Connecting to GitHub

1. Go to your GitHub repository page.
2. Copy the repository URL (HTTPS or SSH).

git remote add origin <repository_url>
    → Links your local repository to a remote one on GitHub.
    Example: git remote add origin https://github.com/username/repo-name.git

git remote -v
    → Verifies the remote URL connection.

---

## Step 4: Pushing Your Code

git push -u origin main
    → Pushes your commits to the `main` branch on GitHub and sets it as the default upstream branch.

For future pushes, you can just run:
    git push

If you are pushing a new branch:
    git push origin <branch_name>

You’ll be prompted for your GitHub username and password or personal access token if using HTTPS.

---

## Step 5: Cloning an Existing Repository

git clone <repository_url>
    → Downloads an existing GitHub repository to your local machine.
    Example: git clone https://github.com/username/repo-name.git

---

## Step 6: General Workflow Example

1. git clone <repository_url>
2. cd into the project folder
3. Make your changes
4. git add .
5. git commit -m "Describe your change"
6. git push origin <branch_name>

---

## Common Tips

- Always run `git status` before committing to see what’s changed.
- Use meaningful commit messages.
- Use branches to keep your work organized and avoid conflicts.
- Before pushing, make sure your branch is up to date by running:
    git pull origin <branch_name>
